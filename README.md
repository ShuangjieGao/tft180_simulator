# TFT180 模拟器

本项目是一个 **逐飞 (Seekfree) TFT180 屏幕原生模拟器**。在 Windows 本地实现了逐飞官方 TFT180 屏幕驱动 API（如 `tft180_draw_point`、`tft180_draw_line`、`tft180_show_gray_image` 等），用于在电脑上直接查看和调试画线与图像显示效果。

工程已内置便携编译器，无需配置环境变量，换电脑即拷即用。

---

## 使用方法

直接双击运行以下批处理文件：
- **`build_and_run.bat`**：编译并运行模拟器
- **`run.bat`**：直接启动模拟器
- **`build.bat`**：仅编译代码

### 快捷键
- **`空格键 (Space)`**：暂停 / 继续
- **`ESC` 键**：退出模拟器
