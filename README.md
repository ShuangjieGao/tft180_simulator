# TFT180 智能车视觉算法模拟器

本项目是针对全国大学生智能汽车竞赛开发的 **逐飞 (Seekfree) TFT180 屏幕原生模拟器**。

通过在 Windows PC 本地模拟逐飞官方 TFT180 屏幕驱动 API（如 `tft180_draw_point`、`tft180_draw_line`、`tft180_show_gray_image` 等），可以直接读取赛道 AVI 录像运行并调试 `image.c` 中的视觉算法。算法代码无需修改，可直接移植到单片机。

工程已内置便携编译器，解压或复制到任何电脑上均**无需配置环境，双击即用**。

---

## 🚀 使用方法

### 1. 运行与编译（推荐脱离 VS Code 直接使用）
直接在文件资源管理器中双击以下批处理脚本：
- **`build_and_run.bat`**：**一键编译并运行**（修改代码后双击它即可自动编译并打开窗口）。
- **`run.bat`**：直接启动模拟器（或直接双击 `main.exe`）。
- **`build.bat`**：仅编译源码，用于检查代码是否有语法错误。

*(若使用 VS Code，也可按 `Ctrl + Shift + B` 快捷键一键编译)*

### 2. 窗口快捷键
- **`空格键 (Space)`**：暂停 / 继续播放（暂停时窗口标题显示 `[PAUSED]`，方便逐像素观察边界）。
- **`ESC` 键 / 窗口 `[X]`**：退出模拟器。

## 💡 如何调试算法

1. 使用任意文本编辑器打开 **`image.c`** 编写你的寻线与元素识别算法。
2. 在算法中直接调用逐飞标准 TFT180 API 画图调试（注意 Y 坐标需加上图像起始行偏移 `TSEL`）：
   ```c
   // 在屏幕图像上绘制识别出的边界点（红点）
   tft180_draw_point(limit_a_b(LB[i] * 160 / image_w, 0, 159), i + TSEL, RGB565_RED);

   // 在两点间绘制辅助线（蓝线）
   tft180_draw_line(x1, y1 + TSEL, x2, y2 + TSEL, RGB565_BLUE);
   ```
3. 保存后双击 **`build_and_run.bat`** 即可在窗口中看到实时的算法识别轨迹。

---

## 📦 迁移到另一台电脑

直接把整个 `tft180_simulator` 文件夹拷贝到新电脑上，**双击 `build_and_run.bat` 即可直接使用**，不需要在新电脑上安装编译器、Python、VS Code 或配置任何环境变量。
